## 2026-09-03 - os.scandir vs pathlib.Path.glob Overhead
**Learning:** In Python, using `pathlib.Path.glob()` or `.iterdir()` creates full `Path` objects and requires separate `.stat()` syscalls for every file to sort by modification time. Using `os.scandir()` caches file stats (like `st_mtime`) directly in `DirEntry` objects, resulting in significantly faster directory reads (2-3x faster in benchmarks on this codebase). This is a critical bottleneck on dashboard endpoints that poll frequently and read large data directories.
**Action:** When sorting or filtering large directories by file metadata (especially `mtime`), always use `os.scandir()` wrapped in a context manager to prevent file descriptor leaks, instead of `pathlib.Path` iterators. We centralized this logic into `core.fs_utils.get_sorted_files_by_mtime` to maintain readability while gaining the performance benefit.
