## 2026-09-11 - Optimize Directory Listing with os.scandir
**Learning:** In Python, iterating over large directories using `pathlib.Path.iterdir()` or `pathlib.Path.glob()` can be a performance bottleneck because methods like `.stat()` have to perform separate system calls for each entry. Using `os.scandir()` provides a significant optimization because it caches `stat()` results (like `st_mtime`) on many platforms. We identified that the codebase frequently fetched `os.stat().st_mtime` to sort session directories, making this a prime candidate for a performance boost. However, since `os.scandir()` returns `os.DirEntry` objects, we need to explicitly cast them back to `Path` objects if downstream logic expects `Path` methods like `.is_dir()`.
**Action:** When creating utility functions or interacting with the file system for directory listings that require sorting by modification time, avoid raw `iterdir()` combined with `.stat()`. Instead, use `os.scandir()` within a context manager (to avoid file descriptor leaks) and extract the `st_mtime` from the yielded entries, falling back to centralized helper functions (like `get_sorted_files_by_mtime` in `core/fs_utils.py`) to reduce repetitive boilerplate.
