## 2024-05-18 - Replacing pathlib with os.scandir for cached st_mtime properties
**Learning:** For file-based backends that sort lists of files by modification time, using `pathlib.Path.glob()` or `iterdir()` results in making separate `stat()` system calls for every returned file when evaluating `p.stat().st_mtime`. ReClaw heavily relies on iterating and sorting files (sessions, runs) and this pattern becomes a real performance bottleneck.
**Action:** When filtering or sorting large lists of files by file properties like `st_mtime`, avoid `Path.glob()` and `Path.iterdir()`. Instead, use `os.scandir()` which returns `DirEntry` objects. These objects cache the `stat()` output retrieved during iteration, avoiding redundant system calls and vastly improving execution speed, cutting the iteration and sorting time almost in half.
