## 2026-09-07 - Optimize File System Traversal
**Learning:** The codebase heavily uses `pathlib.Path.glob()` and `pathlib.Path.iterdir()` paired with `lambda p: p.stat().st_mtime` for sorting files by modification time, particularly in API endpoints and MCP servers. This is inefficient because `pathlib.Path.stat()` issues a new system call for each file. Memory instructions state: "For file system performance, the project prefers using `os.scandir()` instead of `pathlib.Path.glob()` or `iterdir()` to leverage cached stat results (e.g., `st_mtime`). Always wrap it in a context manager (`with os.scandir(path) as it:`) to prevent file descriptor leaks." and "To optimize directory listing and file sorting by modification time, use the centralized helper function `get_sorted_files_by_mtime` located in `core.fs_utils` rather than raw `os.scandir()` or `pathlib.Path.glob()`."
**Action:** Created `core/fs_utils.py` with `get_sorted_files_by_mtime` and `get_sorted_glob_by_mtime` which uses `os.scandir()`. Need to replace usages in `api/main.py`, `scripts/reclaw_platform_mcp_server.py`, `scripts/ravenstack_mcp_server.py`, `scripts/reclaw_api_mcp_server.py`, and `core/job_registry.py`.
