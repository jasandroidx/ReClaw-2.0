## 2026-07-21 - [File system performance]
**Learning:** ReClaw uses an isolated sessions architecture, generating numerous files in `data/sessions/`, `data/runs/`, and other local disk storage directories. When iterating over files for metadata or listing (e.g. `list_pipeline_sessions`, `latest_job`, `list`), using `pathlib.Path.glob()` or `iterdir()` in combination with `.stat().st_mtime` involves O(N) stat syscalls *after* path string manipulation. Since `.stat()` performs a syscall for every file, performance degrades as file counts increase.
**Action:** Use `os.scandir()` which returns `DirEntry` objects containing cached `stat` results (including `st_mtime`). This eliminates the extra `stat()` syscall and path object overhead, providing a significant performance boost (~2-3x faster) on file-heavy endpoints.
